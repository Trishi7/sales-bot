## 8. Findings and notes for the builder, planner and human

1. A title tag is matched as a word: `NOTES_REQUIRE_TITLE_TAGS="[Sales]"` is the word "sales" and
   matches "Sales sync" and "Acme sales call". Use a distinctive tag such as `[SalesNotes]`.
   Documented in `.env.example`, `README.md`, `DEPLOY.md` and the `config.validate()` message; no
   example recommends `[Sales]`. The default stays empty.
2. `sync_status()["exclude_patterns"]` returns the NORMALISED effective patterns (for example
   `nfthing kick off`), not the strings typed in `.env`. The tests compare normalised forms.
3. The `quarantined=` figure in the log line and `sync_status()` counts files moved by THIS process,
   cumulative across syncs. It resets on restart.
4. Builder's deliberate deviation from the plan: the `sync` dict in the notes tool results carries
   only ran/ok/forced/configured/degraded; `error` and `remedy` were dropped because they hold the
   command and variable names. Covered by D8 and E4e. Tested and accepted.
5. Replay-harness fix (mine): the first run flagged a test-mode vs live difference that was only
   the temp path and a wall-clock timestamp; both are now masked before comparing. No product change.
6. Pins on old behaviour that had to be updated: none. No existing `verify_*.py` or test was edited.
7. Not checkable offline (in the checklist): that rclone follows Drive shortcuts in the folder, and
   that the en dash survives `.env` to shell to rclone.
